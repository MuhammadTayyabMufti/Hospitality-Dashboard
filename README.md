# 🏨 Hospitality Data Analysis & Power BI Dashboard

## 📊 Title / Headline

**Hospitality Data Analysis Dashboard | Power BI | 166K+ Records**

An interactive Power BI dashboard designed to analyze hospitality booking, revenue, customer, market, and performance data across **166K+ records**.

---

## 📝 Short Description / Purpose

This project transforms a large hospitality dataset into an interactive business intelligence dashboard using **Microsoft Power BI**.

The dashboard provides a consolidated view of important hospitality KPIs such as **Bookings, Revenue, Number of People, Spend per Sleeper (SPS), Average Selling Price (ASP), and year-over-year performance**.

It is designed to help business stakeholders quickly understand booking patterns, customer segments, market performance, and revenue trends.

---

## 🛠️ Tech Stack

- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data transformation and preparation
- **DAX** – Measures, KPIs, calculations, and year-over-year analysis
- **Data Modeling** – Relationships, date tables, and analytical model
- **Excel / Tabular Data** – Data preparation and source-data handling

---

## 📂 Data Source

The dashboard is based on a **hospitality booking dataset containing approximately 166K+ records**.

The dataset contains information related to:

- Booking dates and arrival dates
- Booking and customer characteristics
- Origin markets
- Countries / markets
- Villa types
- Customer journey
- Booker type
- Number of people
- Revenue
- Spend per Sleeper (SPS)
- Booking-related categories and classifications

> **Note:** The original dataset is not included in this repository if it contains restricted, proprietary, or personally identifiable information. The Power BI template (`.pbit`) is provided as the main project artifact.

## 💼 Business Problem

Hospitality businesses generate large volumes of booking and customer data. Without an effective analytical dashboard, it can be difficult to:

- Monitor booking and revenue performance
- Identify changes in demand over time
- Understand which markets generate the most business
- Compare current performance with previous periods
- Evaluate customer and booking patterns
- Understand revenue relative to the number of travelers
- Identify areas requiring further investigation

The objective of this project is to convert **166K+ hospitality records** into a clear and interactive reporting solution that supports faster, data-driven decision-making.

---

## 🔎 Description

The project follows a business intelligence workflow:

**Raw Hospitality Data → Data Preparation → Data Modeling → DAX Measures → Interactive Visualizations → Business Insights**

The data model contains booking and hospitality attributes together with date dimensions and calculated measures.

DAX measures are used to calculate core KPIs and comparative metrics, including revenue, bookings, people, spend per sleeper, previous-year values, and YoY changes.

The dashboard allows users to explore performance from multiple perspectives, including **time, market, customer, booking type, and hospitality characteristics**.

---

## 📈 Business Impact and Insights

The dashboard can support hospitality decision-making by providing a single analytical view of operational and commercial performance.

### 💡 Key Business Insights Enabled

- **Revenue Performance:** Monitor revenue trends and identify periods of stronger or weaker performance.
- **Booking Trends:** Track booking volumes over time and compare current performance with previous years.
- **Customer Demand:** Analyze the number of people associated with bookings to understand demand patterns.
- **Market Performance:** Compare key geographic markets to identify stronger and weaker source markets.
- **Revenue Efficiency:** Use Spend per Sleeper (SPS) and ASP to evaluate revenue performance beyond booking volume alone.
- **Customer Segmentation:** Examine performance by booker type, customer journey, and other customer-related classifications.
- **Product Performance:** Analyze villa types and related categories to understand demand across different offerings.
- **Trend Monitoring:** YoY measures help identify positive and negative changes in major KPIs.
- **Decision Support:** Interactive filtering allows stakeholders to move from high-level KPIs to specific markets, periods, and customer segments.

### 🎯 Potential Business Value

This type of dashboard can help management and commercial teams:

- Make faster data-driven decisions
- Identify market opportunities
- Monitor revenue and booking performance
- Understand customer behavior
- Detect performance changes earlier
- Improve reporting efficiency
- Support strategic planning and resource allocation

> **Important:** The `.pbit` file contains the Power BI report structure and model, but the template itself does not provide the underlying source data in this repository. Therefore, numerical findings should be calculated after connecting the original dataset.
